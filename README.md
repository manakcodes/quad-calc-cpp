# `quad-calc-cpp`

> A minimal, lightweight C++ based CLI tool to solve quadratic equations in the form of `(ax² + bx + c = 0)`.

---

## 🐙 About

`quad-calc-cpp` is a **lightweight, minimal, CLI based C++ project** developed to solve quadratic equations programmatically. It calculates roots using the **discriminant formula**, handles real and imaginary solutions, and provides a **user-friendly terminal interface**.

---

## 📌 Features

- 🧮 Solves quadratic equations `(ax² + bx + c = 0)`.
- ⏱️ Animated **loading bars**.
- 🎨 Colored CLI output using **ANSI codes**.
- 📐 Displays `equation`, `determinant`, `nature of roots`, `roots`.
- 💾 Dynamic memory management with `new` and `delete`.
- ⚡ Lightweight, header-only modular design.

---

## ⚙️ Requirements

- C++11 or higher compiler (`g++`, `clang++`, `MSVC`).
- `git` (for cloning repository).
- No external libraries required.

## 🛠️ Project Setup

### 1. Navigate to the folder where you want to clone the project repository (example: `Desktop`)

```bash
cd ~/Desktop
```

### 2. Clone the Project Repository

```bash
git clone https://github.com/manakcodes/quadratic-calculator-cpp.git
```

### 3. Navigate To The Project Repository

```bash
cd ~/Desktop/quad-calc-cpp
```

### 4. Run then following command

```bash
make
```

### 5. Run then following command

```bash
make run
```

## After Using The Project Run The Following Command

### Run then following command (to remove the build artifacts)

```bash
make clean
```
